# Мистический сказочный Непал

Лендинг авторского путешествия. 8 дней, 16–23 ноября 2026.

Сайт: **https://nepal-2026.github.io**

## Как устроено

Статическая страница без сборщиков и зависимостей. Ничего устанавливать не нужно: открыл `index.html` в браузере — увидел сайт.

```
index.html      скелет страницы + все тексты в блоке <script id="data">
styles.css      все стили, включая мобильные (медиазапросы 1050px и 760px)
app.js          рендер: собирает разметку из данных
content.json    те же тексты отдельным файлом — удобно читать и диффить
images/         22 фотографии (jpg)
```

Важно: страница рисуется скриптом из JSON. Разметки дней, карточек и блоков в `index.html` нет — она генерируется в `app.js` функцией `render()`. Если нужно менять структуру блока, правится шаблон в `app.js`; если нужно менять слова — блок данных.

### Где менять тексты

В `index.html`, блок `<script id="data" type="application/json">`. Ключи говорящие:

| Ключ | Что это |
| --- | --- |
| `heroTitle1`, `heroTitle2`, `heroLead`, `heroWhen` | первый экран |
| `facts` | пять плашек под первым экраном |
| `intro*` | блок «В сказку можно приехать» |
| `moments` | три карточки «То, что запомнится» |
| `route` | тёмная плашка с маршрутом |
| `days` | восемь дней: место, заголовок, курсивная врезка, абзацы, картинка |
| `mountain*` | баннер про рассвет |
| `comfort` | три колонки «Как это будет?» |
| `authors` | Лена и Муштари: имя, абзацы, слот под фото |
| `price*`, `incl`, `excl` | блок стоимости |
| `faq` | вопросы и ответы |
| `bar*` | липкая полоска снизу на телефоне |

`content.json` — копия этих же данных. Источник правды — блок в `index.html`; при желании можно переключить на загрузку `content.json` через `fetch`, тогда `index.html` станет совсем тонким.

### Картинки

Все в `images/`, привязка — через CSS-классы в конце `styles.css`:

```css
.im-hero-drug { background-image: url("images/hero-drug.jpg"); }
```

В данных указывается только имя класса без префикса: `"img": "hero-drug"`.

## Деплой

GitHub Pages, ветка `main`, корень репозитория. Пуш в `main` — через минуту сайт обновился. Никаких экшенов настраивать не нужно.

## Что нужно доделать

### 1. Кнопки никуда не ведут — главное

Четыре точки действия, все сейчас с `href="#price"` (просто прокрутка к цене):

- «Хочу в эту сказку» — первый экран, ключ `heroBtn`
- «Забронировать место» — блок стоимости, ключ `priceBtn`
- «Забронировать» — липкая полоска снизу на мобильном, ключ `barBtn`
- «Что нас ждёт» — внутренняя ссылка на `#about`, её менять не надо

Нужно: телеграм организатора, форма заявки или ссылка на оплату предоплаты (50% = 100 000 ₽). Ссылки правятся в `app.js` — поиск по `href="#price"`.

### 2. Подвал

Сейчас в футере одна строка и ссылка «Наверх». Нужен нормальный подвал: контакты, договор-оферта, политика обработки данных, реквизиты.

### 3. Финальный блок перед подвалом

Страница обрывается на вопросах и ответах. Нужен закрывающий экран: одна фраза и кнопка.

### 4. Фотографии организаторов

В блоке «Поедем вместе» два слота с пунктирной рамкой и подписями «Фото Лены» и «Фото Муштари». Когда появятся файлы: положить в `images/`, добавить правило `.im-lena` / `.im-mushtari` в `styles.css`, вписать имя класса в `authors[i].img` — рамка исчезнет сама.

### 5. Аналитика

Не подключена. Ожидается Яндекс.Метрика — скрипт в `<head>` в `index.html`.

## Что учесть

- **Лицензии фотографий.** Двадцать кадров — Unsplash, коммерческое использование разрешено. Два (`sluzhba-truby.jpg` — монахи с трубами, `patan-rassvet.jpg` — площадь Дурбар) взяты из открытых источников, автор не установлен. До продвижения сайта их лучше заменить или выяснить права.
- **Цена.** 200 000 ₽ за человека, доплата за одноместное 36 000 ₽, предоплата 50%. Если понадобится показывать доллары, курс согласовать с организаторами: 200 000 ₽ ≈ 2 200 $, а не 2 400 $.
- **Мобильная вёрстка.** Медиазапросы на 1050px и 760px. Липкая полоска снизу (`.paybar`) показывается скриптом после первого экрана, у неё учтён `safe-area-inset-bottom`.
- **Шрифты** подключены с Google Fonts: Prata для заголовков, Golos Text для текста. Фолбэки прописаны.
